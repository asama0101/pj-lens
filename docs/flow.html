pj-lens の動きの流れ

「思った動作と違わないか」を点検するための図です。5 本の流れを、3 つのレーン（あなたの操作・Claude の判断と会話・スクリプトの処理）で描いています。各マスの右下の小さい文字は、根拠のファイルです。

あなたの操作 Claude の判断・会話 スクリプトの処理（Node.js。Excel の読み取りだけ Python）
書き込みデータファイルや設定を書く 承認あなたの承認を待つ 注意警告・案内を出して続ける 止まるそこで処理を終える 未確認実機で動かして確かめていない
  1. 初期設定（/pj-lens:init）
  2. 予定表の接続設定（/pj-lens:mcp）
  3. 取り込み（/pj-lens:intake）: Excel の作業一覧／予定表の会議／会議のキーワード規則
  4. 見張り（/pj-lens:watch）と予定表の自動更新
  5. 画面からの依頼（画面下端の帯「Claude Code に依頼する」）

用語: 「データファイル」= 作業フォルダの .pj-lens/data.json。「画面」= pj-lens.html。「設定フォルダ」= プラグイン専用の保存場所（~/.claude/plugins/data/ の下）。「見張り」= 画面からの依頼を待ち受ける Claude Code の処理。

3. 取り込み（/pj-lens:intake）

Excel の作業一覧（WBS）、予定表の会議、会議のキーワード規則を、データファイルに取り込む。Excel と規則は「読む → 変更案の表 → 承認 → 書き込み」の順で、承認の前にタスクは変わらない。予定表の会議は、表も承認もなしで更新する（確認済みの実績は消さない。止めた理由があって、あなたが削除を認めたときだけ消える）。メール・議事録・メモの本文は、ここでは取り込まず、画面の帯に貼って依頼する（流れ 5）。

対象外（自分だけの予定）の判定

自分 = メールアドレスか名前（前後の空白と大文字小文字を区別しない完全一致）が /pj-lens:mcp で設定したものと一致。会議室 = 種別が会議室・備品、または名前に設定した言葉（既定「会議室」）を含む。自分と会議室を除いて参加者が 0 人なら対象外
参加者の項目がない予定 → 不明なので取り込む。参加者の形が崩れている（null・文字列）→ 不明として取り込む
自分のメールアドレスも名前も未設定 → 何も除かない。参加者つきの予定があれば注意「/pj-lens:mcp で設定してください」
設定済みでも、どの予定にも参加者がない → 注意「予定表の MCP が参加者を返すか確認してください」
設定ファイルの指定が正しくない（selfEmails が配列でない、など） → 止まる理由を出すtools/intake.js / src/import/mcpconf.js validateMcpConfig
設定フォルダが決まらない（環境変数も --data もない） → 流れ 2 と違って止まらない。自分だけの予定を除かずに続け、参加者つきの予定があれば注意「設定を読めていない」の警告を出すtools/intake.js（pickHome） / src/import/calendar.js excludeSolo
